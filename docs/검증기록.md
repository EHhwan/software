# 검증 기록: AI 초안 vs 본인 수정

> 1·2회차와 같은 형식이 정해져 있으면 그 형식으로 옮긴다. 코딩 AI에게 받은 코드를 쓸 때마다 한 줄씩 남긴다.
> **직접 실행해 보고, 직접 고친 것만** 적는다.

## 1차 (Flask 기본 구조, DB, 회원 기능): AI 초안 범위
직접 확인할 것:
- [ ] `python run.py` 실행 → 메인, 회원가입, 로그인, 마이페이지, 로그아웃 화면 확인
- [ ] 잘못된 입력(짧은 아이디, 다른 비밀번호, 이미 있는 아이디·닉네임)으로 가입해 보기
- [ ] 로그인하지 않고 주소창에 `/me` 입력 → 로그인 화면으로 가는지
- [ ] DB 파일(`instance/recipe_mix.db`)을 SQLite Viewer로 열어 비밀번호가 해시로 저장됐는지
- [ ] `models.py` 의 테이블 구조가 요구사항(재료명·수량·단위, 인분, 조리 시간, 순서별 과정, 출처)과 맞는지
- [ ] `python -m pytest tests -q` 통과

## 2~6차 (레시피·커뮤니티·AI 믹스·보유 재료 추천·저장): AI 초안 범위
직접 확인할 것:
- [ ] `python seed_demo.py` 후 둘러보기: 검색(재료 이름으로도), 카테고리, 조리 시간, 작성 방식, 최신순·인기순
- [ ] 레시피 등록·수정·삭제, 다른 사람 레시피는 수정 화면이 403 으로 막히는지, '나만 보기' 레시피는 다른 사람에게 안 보이는지
- [ ] 상세에서 인분 [− +] → 재료량(달걀 4~5개, 대파 1/2대) 계산이 맞는지, 조리 모드, 텍스트 복사
- [ ] 좋아요·즐겨찾기를 두 번 누르면 취소되는지, 마이페이지 즐겨찾기 탭
- [ ] **실제 Gemini 로** AI 믹스: 결과의 재료 분량·단위가 자연스러운지, '달라진 점'과 이유가 맞는지 → 프롬프트 수정 기록에 남기기
- [ ] **실제 Gemini 로** 보유 재료 조정: 대체 재료와 '추가로 필요한 재료'가 구분되는지
- [ ] AI 결과 '수정 후 저장' / '내 레시피로 저장' → 나만 보기로 저장되고 원본 출처가 보이는지
- [ ] `.env` 의 API 키를 일부러 틀리게 바꿨을 때 오류 안내가 뜨고 화면이 깨지지 않는지

| 날짜 | 파일·기능 | AI가 만든 초안 | 직접 확인한 방법 | 발견한 문제 | 본인이 수정한 내용 |
|---|---|---|---|---|---|

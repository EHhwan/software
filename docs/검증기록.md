# 검증 기록: AI 초안 vs 본인 수정

> 1·2회차와 같은 형식이 정해져 있으면 그 형식으로 옮긴다. 코딩 AI에게 받은 코드를 쓸 때마다 한 줄씩 남긴다.
> **직접 실행해 보고, 직접 고친 것만** 적는다.

## 1차 (Flask 기본 구조, DB, 회원 기능): AI 초안 범위
직접 확인할 것:
- [ ] `python run.py` 실행 → 메인, 회원가입, 로그인, 마이페이지, 로그아웃 화면 확인
- [ ] 잘못된 입력(짧은 아이디, 다른 비밀번호, 이미 있는 아이디·닉네임)으로 가입해 보기
- [ ] 로그인하지 않고 주소창에 `/me` 입력 → 로그인 화면으로 가는지
- [ ] DB 파일(`instance/recipe_mix.db`)을 SQLite Viewer로 열어 비밀번호가 해시로 저장됐는지
- [ ] `models.py` 의 테이블 구조가 요구사항(재료명·수량·단위, 인분, 조리 시간, 순서별 과정, 출처)과 맞는지
- [ ] `python -m pytest tests -q` 통과

| 날짜 | 파일·기능 | AI가 만든 초안 | 직접 확인한 방법 | 발견한 문제 | 본인이 수정한 내용 |
|---|---|---|---|---|---|
| 예) 10/28 | 회원가입 | 아이디 4~20자 영어 소문자 | 한글 아이디로 가입 시도 | 안내 문구가 어색함 | 문구를 ○○로 수정 |

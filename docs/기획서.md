# 공지핏 기획서 (8~9주차)

> 이 문서는 틀이다. 8주차 승인 내용과 9주차 설계 결과로 직접 채운다.

## 1. 한 줄 소개
나에게 해당되는 학교 공지만 골라 3줄 요약과 마감일로 알려 주는 AI 비서

## 2. 해결하려는 문제
- 학교 공지(장학, 학사, 비교과, 취업)는 길고 많아서 나에게 해당되는 공지를 놓친다.
- 공지마다 대상 조건(학년, 학점, 학과, 수혜 이력 등)이 달라 읽어 봐야 해당 여부를 알 수 있다.
- (직접 겪은 사례를 추가)

## 3. AI 기능 정의 (Gemini)
| 항목 | 내용 |
|---|---|
| 입력 | 공지 본문(붙여 넣기 또는 링크) + 내 프로필(학과, 학년, 평점, 수혜 이력 등) |
| Gemini가 하는 일 | ① 3줄 요약 ② 해당됨 / 해당 안 됨 / 확인 필요 + 이유 ③ 마감일·준비물 추출 |
| 출력 형식 | JSON (요약, 판정, 이유, 마감일, 준비물) → 서버에서 검증 후 저장 |
| 왜 AI인가 | 대상 조건이 공지마다 자유로운 문장이라 if문으로 프로필과 비교할 수 없음 |
| 실패 시 | 원문은 그대로 저장·표시하고 "AI 분석 실패, 원문을 확인해 주세요" 안내 |

## 4. 화면 목록 (9주차)
- [ ] 메인: 공지 목록 (마감 임박 순, 해당 여부 배지)
- [ ] 공지 추가: 본문 붙여 넣기 → 분석 결과 미리보기
- [ ] 공지 상세: 요약, 판정 이유, 마감일, 준비물, 원문
- [ ] 내 프로필: 학과, 학년, 평점 등
- [ ] (추가 화면)

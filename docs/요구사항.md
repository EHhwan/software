# AI 레시피 믹스 커뮤니티: 요구사항 (승인된 주제)

## 1. 개요
사용자가 레시피를 등록·공유하고, Google Gemini API로 **두 레시피를 조합**하거나 **보유 재료에 맞게 레시피를 재구성**하는 웹서비스. 실제 배포까지 한다.

## 2. 기술 스택
HTML/CSS/JavaScript/Bootstrap · Python Flask · SQLite(개발) / PostgreSQL(배포) · Google Gemini API · Render. API 키는 환경변수로 관리.

## 3. 필수 기능
**A. 회원:** 회원가입·로그인·로그아웃, 비밀번호 해시 저장, 내 프로필과 내 레시피 조회, 로그인 사용자만 레시피 등록·AI 결과 저장

**B. 레시피 등록·관리:** 요리 이름, 설명, 재료(이름·수량·단위), 인분, 조리 시간, 순서별 조리 과정, 작성자. 수정·삭제는 작성자만. 사진 없이 텍스트로 등록 가능

**C. 커뮤니티:** 전체 목록, 상세, 좋아요 추가·취소(사용자당 레시피별 1회), 최신순·인기순(좋아요 수, AI 사용 안 함), 검색, 다른 사용자 레시피를 AI 믹스 대상으로 선택

**D. AI 레시피 믹스 (가장 중요):** 내 레시피 + 다른 사용자 레시피 + 조합 목표 → 서버가 재료·양념·순서·인분·시간을 Gemini에 전달 → 공통점·차이점 분석, 재료 중복·양념 과다·순서 충돌을 고려해 새 레시피 생성.
결과: 새 요리 이름, 특징, 재료와 정확한 수량, 단계별 조리법, 예상 시간, 원본과 달라진 점, 변경 이유. 사용자가 확인·수정 후 저장, 원본 2개 출처 표시. **단순히 재료를 합치지 않고 조리법의 적합성을 판단하고 이유를 설명**

**E. 보유 재료 기반 추천:** 보유 재료 입력 → **DB에서 후보 레시피 조회(일반 코드)** → Gemini가 후보와 보유 재료 분석 → 적합한 요리 추천, **대체 재료와 바뀐 조리법 제안(AI)**, 추천 이유와 추가로 필요한 재료 구분 표시

**F. AI 결과 관리:** 미리보기, 수정, 내 레시피로 저장, 다시 보기, 커뮤니티 공개, 원본↔조합 레시피 출처 관계 저장

## 4. Gemini 구현 요구사항
Flask 서버에서만 호출 · JSON 응답 요청 후 구조 검증 · 분량·단위 일관성 · 실패·사용량 제한 시 오류 메시지 · AI 결과는 실제 조리를 보장하지 않으므로 사용자가 검토 · API 키를 GitHub·프론트엔드에 노출하지 않음

## 5. 주요 페이지
메인(인기·최신) · 로그인/회원가입 · 레시피 목록·상세 · 레시피 등록/수정 · AI 레시피 믹스 · AI 보유 재료 추천 · 마이페이지(내 레시피, AI 레시피)
